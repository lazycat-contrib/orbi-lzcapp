Orbi 正在运行

熄灯软件工厂：给 GitHub Issue 打上 ai-ready 标签，自动获得经过独立评审、合并的 PR 和打 tag 的 Release。

快速开始

  1. 在安装时填写的任务池仓库（OWNER/REPO）里创建一个 Issue，用两种形状之一描述任务：
    修复：「when X, should Y, actually Z」；变更：「when X, the user should be able to Y; today they cannot because Z」
  2. 给 Issue 打上 ai-ready 标签（runner 首次启动时已自动创建 12 个平台标签）
  3. 两个 tick 内（timer 每 5 分钟）Issue 将自动流转 ai-in-progress → ai-pr-opened，经独立评审后合并

查看运行状态（SSH 到设备后执行）

docker exec -u orbi -e XDG_RUNTIME_DIR=/run/user/1000 orbi \
  journalctl --user -u orbi-tick@timer -n 50 --no-pager
orbi status队列与当前任务
orbi doctor部署体检
docker logs orbisetup 结果与 systemd 控制台

常用标签

ai-ready执行开关（你打）
ai-in-progress / ai-pr-opened / ai-merged交付状态（runner 管理）
ai-fix-needed / ai-blocked需人介入（runner 管理）
ai-ready + ai-release发布任务：正文声明 ## Release 块（version / base_branch / scope）

修改配置（GitHub Token、模型 Provider）：重新部署应用并更新设置向导参数即可，entrypoint 每次启动都会从注入变量重新生成凭据文件。完整文档见 docs.orbi.build。
